# speedtest

Консольный скрипт на Node.js: делает 10 последовательных запросов к указанному адресу, дожидается полного ответа на каждый и считает скорость скачивания.

## Требования

Node.js 18+. Зависимостей нет.

## Запуск

```bash
node speedtest.js <url>
```

Пример:

```bash
node speedtest.js https://proof.ovh.net/files/10Mb.dat
```

## Вывод

```
Target: https://proof.ovh.net/files/1Mb.dat

# 1     1.05 MB   1371 ms      6.12 Mbit/s
...
#10     1.05 MB    504 ms     16.66 Mbit/s

Requests:        10
Downloaded:      10.49 MB
Average time:    896 ms
Download speed:  9.36 Mbit/s
```

## Единицы измерения

| Величина | Единица |
|---|---|
| Объём | MB — мегабайты, 1 MB = 10⁶ байт |
| Время запроса | ms — миллисекунды |
| Скорость | Mbit/s — мегабиты в секунду, 1 Mbit = 10⁶ бит |

Мегабиты в секунду выбраны, потому что в них указывают скорость провайдеры и сервисы вроде Speedtest.

## Как считается

- Время запроса — от отправки до получения последнего байта тела ответа.
- Среднее время — сумма времени всех запросов / 10.
- Скорость — общий объём × 8 / суммарное время запросов.
- Ответ со статусом не 2xx останавливает замер с кодом выхода 1.
